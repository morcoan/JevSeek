# JevSeek v0.2.3 — schema-determined argument bypass

## What's changed

- **Skip unnecessary generation:** after Jev selects a tool, code supplies its arguments directly when the entire argument object is fixed by a conservative schema subset. This removes a Flash/Bonsai generation call without adding another Jev call.
- Supported fixed cases include closed empty objects, required constants/singleton enums/nulls and closed required nested objects. Optional, free-form, reference or unsupported schemas retain the original generator and original context. No requested parameter is silently replaced with a default.
- Usage/activity records distinguish a skipped generator call from actual provider usage. `JEV_ARGUMENT_OFFLOAD=off` restores the original always-generate behavior.
- The complete public research archive is included in the source download: successes, negative results, limits, cancelled work and incomplete prototypes. **Unvalidated neural argument filling and other non-winning paths remain research-only**, not enabled in the app.
- Build metadata records SHA-256 hashes of bundled application source files. Offline EXE checks now verify both the fixed-argument bypass and unchanged free-form fallback, with model requests blocked.

## Update

Close the old app and replace it with **JevSeek.exe**. Existing keys, preferences, saved conversations and local Bonsai assets remain in the normal personal data directory. Review uncertain/interrupted tool effects before resuming; an update does not replay them automatically.

Windows x64, **unsigned**. Check `SHA256SUMS.txt`. The app bundles Python and Fixed Version WebView2; Python/Node are not required to launch it, but tools needed by your workspace projects are not bundled. Do not disable SmartScreen/Defender. The Microsoft runtime terms and privacy notice still apply.

## Scope and verification

This is a narrow, deterministic cost optimization—not general intelligence, automatic neural argument offloading, or a claimed whole-agent saving percentage. The previously published34%/85%estimated API savings concern a separate bounded decision endpoint; they are **not** v0.2.3coding-session savings.

The release gate covers offline Python/frontend tests, the production build, byte/secret/source audits, and an actual EXE isolated from the checkout with Windows-only PATH: native file/shell tools, temporary vault roundtrip/removal, bundled browser/native bridge, and MCP helper. No paid model calls, local model inference or benchmark VM launches are required. Test reports remain local; hashes identify the published assets. Windows11 is the tested host, not certification of every Windows version or a fresh VM.
